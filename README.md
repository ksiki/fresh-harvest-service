# 🌱 «Fresh Harvest»

## 1. Общие сведения

**Название продукта:** «Fresh Harvest»  
**Платформа:** Telegram Mini App (TMA)

### Целевая аудитория

**Продавцы:**
- Частные лица  
- Дачники  
- Фермеры

**Покупатели:**
- Городские жители  
- Путешественники  
- Дачники-соседи  

## 2. Цели и задачи

Создание удобного и доступного инструмента для прямой коммуникации между производителями сельхозпродукции и потребителями.  

Основной упор делается на:
- Простоту использования
- Геопозиционирование  

## 3. Технологии

- **python**
- **fastapi**
- **aiogram**
- **postgreSQL + postGIS**
- **rabbitMQ**
- **alembic**
- **docker compose**
- **poetry**
